## Parser and core

MAX_STR_LENGTH is 4096 instead of 1024. The source FU line is 1043 characters;
its 16 FU masks and the reservation-station connections are preserved.
The former issue_width=8 is now rename_width=8 and dispatch_width=8, following
upstream 967e887. Other retained core/cache values come from the Mobius file.

## Memory resources and prefetch

The old shared mem_req_buffer_entries resource no longer exists. The architecture
sets icache/dcache/mlc/l1 MSHRs to 16/32/32/32, respectively. The experiment's
baseline override of mem_req_buffer_entries=64 is ported to dcache/mlc/l1 MSHRs
of 64 each; the independent icache file stays 16. This is an explicit new-model
capacity choice, NOT an equivalent total shared capacity of 64.

The old prefetch watermark of 4 becomes demand reserves of 4 in both first-level
MSHR files. The legacy stream prefetcher becomes one LLC-trained TYPE_STREAM,
DEST_L1 instance. pref_oracle_train becomes pref_oracle_train_on. Old full-queue
overwrite is replaced by upstream pref_retry=1; arbitration, request merging,
bank timing and queue behavior follow current upstream. These can change IPC.

## DRAM

The built-in DDR4_3200_Mobius_8Gb_x8_4ch_2rank configuration is generated by
src/ramulator2/gen_configs.py using the pinned Ramulator 2 Python DSL. It keeps
DDR4-3200, 4 channels, 2 ranks, 8 Gb x8, 64-bit channels and 625000 fs tCK.

Effective DDR4 timings retained from Mobius: nCL/nRCD/nRP=22, nRAS=56, nRC=78,
nCWL=16, nBL=4, nCCDS=10, nCCDL=2, nWTRS=12, nWTRL=24. Inherited legacy
3200-table values are also pinned: nWR=24, nRTP=12, nRRDS=4, nRRDL=8,
nFAW=34, nRFC=560, nREFI=12480, nCS=2. The unusual nCCDS/nCCDL values are
intentional preservation of the supplied file, not a JEDEC timing recommendation.

Legacy tCCD, tWTR, tRPpb/ab and tRCDR/W were not consumed by Mobius's DDR4
implementation; they are removed rather than treated as extra timing constraints.
The disabled legacy command trace options are removed.

Ramulator 1 FRFCFS_Cap is replaced by current upstream Ramulator 2 FRFCFS.
Controller scheduling, row-hit handling, refresh and other backend behavior
are NOT claimed equivalent even though organization and timing values match.
